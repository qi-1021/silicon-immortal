# 术语与模型边界

| 术语 | 本作中的含义 | 需要注意 |
| --- | --- | --- |
| SoC | 核心、缓存、互连、加速器与接口组成的系统方案 | 不只是CPU数量 |
| IP | 可复用硬件定义/模板 | 这里不是商业采购授权合同 |
| ISA | 指令与架构状态的约定 | 同一ISA可以有不同微架构 |
| x86 / IA-32 | Intel、AMD常见指令家族；IA-32是它的32位形式 | 本作有32位与64位整数子集，64位含16GPR和32位别名零扩展；无OS/SIMD |
| RISC-V / RV32 | 开放指令集家族；RV32是32位寄存器形式 | 指令扩展需明确实现，不等于整套标准自动支持 |
| Arm64 / AArch64 | 64位Arm架构状态与指令家族 | 本作仅明确列出的整数指令 |
| 扩展ISA | 在基础ISA上增加的可选能力，例如RV32 M/Zbb | 扩展存在不自动保证软件利用 |
| 微架构 | 实现ISA的具体资源和调度 | 本作仅实现明确列出的结构参数 |
| IPC | 每周期完成的指令数 | 要连同程序、ISA和计数方法一起比较 |
| ROB | 乱序核心的在途/顺序提交队列 | 本作没有完整投机恢复和有限物理寄存器 |
| ALU | 整数运算资源 | 数量受总发射/依赖限制 |
| Cache line / way | 缓存行长与组相联路数 | 容量本身不能推导所有命中率 |
| SIMT / warp / lane | 一组lane执行向量路径，warp可交错安排 | 没有完整GPU线程/驱动模型 |
| MAC / PE | 乘累加运算与阵列处理单元 | 计TOPS时本作每MAC两op |
| TOPS | 每秒万亿次运算的理想峰值 | 需注明精度、稠密/稀疏和MAC计法 |
| RAW / Bayer / demosaic | 原始采样、彩色滤波排列、重建RGB | 本作只有基本RGGB/双线性路径 |
| PDN | 芯片/封装供电路径的等效电阻与压降 | 可输入mΩ或按投入映射，没有真实网格提取/瞬态去耦模型 |
| PPA | 功耗、性能与面积 | 本作SoC PPA为未校准估算 |
| PVT | 工艺、电压、温度条件 | 这里是相对情景系数，不是SPICE角落 |
| bin | 可满足某频率档位的die比例 | 教学概率代理值，不是生产测试结果 |
| NRE | 一次性研发/光罩/适配费用 | 与每颗裸die、封装、测试费用分开 |
| Chiplet | 多die组成的方案 | 当前同节点两die、2.5D、逻辑总图 |
| Amdahl | 串行部分限制并行加速 | 核多不等于任意任务快 |
| Roofline | 计算与带宽共同限制吞吐 | 当前输入是抽象运算强度，不是应用trace |

## 哪些是真正执行，哪些是估算

**执行的功能模型：** RV32I/M/Zbb、IA-32、AMD64/Intel64与AArch64的明确整数子集；逐lane FP32任务；有限整数GEMM；基础RAW图像流水线。指令由汇编解析执行，不从二进制取指。

**资源调度：** 对正确功能轨迹计算依赖和资源时序，含有限在途队列、运算端口、缓存延迟、SIMT驻留与阵列填充/排空。没有完整投机、异常恢复、cache一致性和OS。

**教学估算：** SoC面积、Fmax、功耗、热、良率、互连、封装、市场与利润。资源数量可能增加估算代价，没有任何论文自动证明本作系数准确。

**独立真实RTL：** 随项目保留PicoRV32固定提交，可通过Icarus运行ADDI/ADDI/SW冒烟。它与玩家功能/调度模型独立，玩家设计不会自动生成该RTL。
