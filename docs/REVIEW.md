# 0.1.0-alpha.5 工作区审查

当前只发布源码与平台脚本，无exe/app；Windows run.bat、Mac run.command、Linux run.sh。按用户要求停用重复三平台验证，Linux未运行平台测试。

本轮针对性本地检查覆盖64位x86语义/REX编码/32位写零扩展/flags/qword、.cor/.sil重放、自由沙盒诊断/PDN、独立存档与表格列宽。没有把历史全套测试数字或旧跨平台成功套用成新版已验证。实际截图查看核心表格、x64设计、自由工作区、PDN和诊断，标题与输入宽度一致。

x86-64来源核对Intel SDM September2026：Vol.1 §3.4.1.1 pp.3-12–3-13；Vol.2A ADD/IMUL/Jcc；Vol.2B MOV/Shift。只有使用范围内的整数语义与编码，无OS/SIMD、RIP/索引地址、8/16位别名、完整取指。64KiB对齐内存限制属于游戏。PPA仍为game_assumption，没有用手册认证物理精度。

核心模板扩展为精简/均衡/宽发射/计算吞吐方向，hardware实际参加验证和调度。沙盒自由选择、不设产品任务门槛，但诊断展示真实模型缺口；生成预览不把signoff_ready标为物理/产品通过。源文件已保留新PDN参数，旧文件0默认沿用投入映射。

23份正式来源、99条遗留引用保持审计范围。代码、图文、例子、测试与必要许可公开，玩家saves、虚拟环境、研究缓存、内部工作记录排除。GitHub与Forgejo拉取镜像同步，发布附件仅源码ZIP与摘要。
