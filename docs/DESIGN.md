# 桌面工作台设计

## 体验

从项目定义进入架构、物理实现、布局、封装、工程验证、签核、发布报告与样片展示。修改方案后可返回任一步骤。未流片的发布页与展示页显示“预估”或“设计预览”；设计发生变化后，之前的发布状态不再适用于新版本。

项目状态、尺寸、功耗、性能和成本固定在顶部。侧栏排列九个步骤，独立提供教学、图鉴、文献和LAB入口。模式选择常驻顶部。最小窗口 1180×760；参数列和报告区可以滚动。

## 视觉与交互

视觉系统位于 `ui/theme.py`。石墨背景、低饱和模块色、铜色主要操作；暖白主文本，浅灰次级文本。保留清晰的按钮按下、悬停和键盘焦点反馈。

Card 使用布局最小尺寸约束，防止动态参数或长文案压扁控件。图片检查器维持纵横比，支持滚轮缩放、拖动、双击/0 复位和键盘 +/-。项目卡可用 Enter/Space 激活。`Ctrl+K` 与 `⌘K` 均可调用查找。

高频滑杆、导航和搜索不添加动画。首页和已发布样片允许简短淡入；侧栏可关闭动效，也支持 `SILICON_PROFESSOR_NO_ANIM=1`。不滚动伪造尚未确定的评分数字。

## 本次采用的技能

使用用户指定仓库的 [emil-design-eng/SKILL.md](https://code.qiisme1021.space/isqi/skills/src/branch/main/skills/emil-design-eng/SKILL.md)。它重点要求解释动效用途、保持响应、正确层级与状态、避免高频交互动画；其网页示例按 Qt 控件能力实现，没有新增前端框架。

| Before | After | Why |
| --- | --- | --- |
| 高饱和描边和网格背景 | 中性面板和少量铜色强调 | 减少视觉竞争 |
| 横向八步导航 | 固定侧栏九步流程 | 工程检查有独立空间 |
| 数值变化时反复动画 | 重算直接更新结果 | 参数实验保持响应 |
| 图像随 QLabel 撑大布局 | 独立缩放、平移检查器 | 窗口大小与图像分离 |
| 按钮阻塞规则与引擎不同 | 共用 signoff.ready | 检查结果可预测 |
| “真实 die shot”指代示意图 | 仅展示玩家布局生成的模拟图，导出带生成标记 | 保持展示与玩家设计一致 |
| x86/A64参数页仍出现RV32扩展选项 | 只在RV32页显示M/Zbb，架构卡提供各自原文 | 防止把不同ISA的扩展混为一谈 |

## 数据表达

重写 28 个芯片解读与教学讲义；移除夸张故障断言和无依据排名。近期低置信条目保留为待核验实验输入。SP 分、AI 综合分、规划完成度、游戏事件概率与工艺签核数据分别说明。

独立照片已移除；玩家模拟PNG自带生成标记。Chiplet 逻辑总图的限制在视图与导出中保留。

## 复现与检查

`tools/capture_screens.py` 使用临时存档，在 1500×940 和 1180×760 生成截图；处理 Qt 布局与延后删除事件，避免捕获未稳定的控件几何。测试覆盖主要数值趋势、教学解法、筛选跳转、签核阻塞、图像模式、重算刷新与导出。数学假设见 [MODEL.md](MODEL.md)。

## 启动与实验室

启动页采用本地铜色芯片/S路径SVG标志，保留用户指定的中英标语、游戏说明与`powered by isqi`，显示alpha版本。主操作无需等待倒计时，无联网开屏；有设计时预览玩家的模拟die，空项目显示标志。

LAB默认进入核心设计台：左侧命名草稿，中央结构图，右侧模块参数；验证/测试台、已发布IP和JSON定义分别有页签。可独立新建CPU/GPU/NPU/ISP，无需SoC或课程。草稿自动保存、复制；硬件改变使旧验证失效，测试输入改变只清除测试输出。

“实验与教学”保留九个实验、18节进阶课程、三个可运行CPU子集和35项目录。初级/中级折叠专家参数，高级/专业展开；隐藏不改变值。设计操作与课程入口均可达。结构图可滚动，点击或方向键选择模块定位参数，未实现的模块不会画入结构。

输入、结果、源码与来源均可滚动。ISA目录区分RV32编码表和IA-32/A64范围卡；历史目录不将未实现项写成可运行选项。切换实验返回输入/轨迹页；切换到首页或LAB会清除流程步骤的旧选中状态。

`.cor`导入重新验证功能模型；`.sil`内嵌自定义资产及模板全参数/名称/参考制程。架构页显示文件内模板与实际加速器绑定；IP页可编辑当前SoC内嵌核心。失败反馈含字段与来源版本。CPU跨ISA必须明确替换集群，GPU/NPU/ISP可以直接绑定。源码与许可页提供独立PicoRV32冒烟入口。

当前源码版用平台脚本启动；菜单明确指定不透明QMenu背景。x86正式参与SoC/LAB教学核心设计，名称先用常见家族再注明32位IA-32范围。CPU性能套件独立显示指令数、周期、IPC与基线，短程序瓶颈说明紧邻结果。
