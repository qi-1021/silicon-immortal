# 0.1.0-alpha.6 · 拯救芯片与执行观测

源码与启动脚本发行；公开版本以Release标签和附件为准。

- 12份独立档案：Pentium、Barcelona、Cougar Point、骁龙810/888/8EE6和Tensor G1–G6。三类历史故障支持限域教学试验；9份移动芯片档案展示具体架构、测量条件和性能合同，反事实模型仍待校准，不能通过旧通用热模型通关。
- Pentium采用文献SRT商选择漏项与收敛边界；Barcelona采用PTE A/D更新、驱逐、外部探测和规避代价；Cougar Point还检查桥接后的共享带宽。功能恢复不能掩盖严重性能损失。
- 移动性能合同要求单核保留至少90%、多核/GPU峰值至少85%、持续绝对吞吐不退步；这些是游戏合同，不是厂商规格。必需测量缺失、跨基准版本或设备条件混用不能授予通过。
- 修正A20 Pro等代际错配、Qualcomm GPU身份和Tensor核心配置；事实与教学参数分别标明。Apple A系列蜂窝基带位于应用处理器Die之外，M系列不配置蜂窝基带，旧文件快照不会被目录更新替换。
- Geekbench 6实测独立于SP分数，保留设备、版本与出处；没有工作负载校准时不能从整数IPC或单核×核数推算GB6。
- CPU可用两上下文SMT、最多16个MSHR和二位方向预测；两个实际程序共享资源，并与独跑周期比较。不执行错误路径，无OS或缓存一致性。
- CPU/GPU/NPU/ISP“执行观测”支持播放、逐周期、线程/阶段切换，展示提交、向量掩码、阵列波前和ISP中间像素。
- 镜像更新：Forgejo优先，GitHub代理与原站备用。逐文件清单/SHA-256校验，重启事务安装、备份与失败恢复；存档/虚拟环境/个人设计保留，Git开发目录禁止覆盖。
- 源码发布增加update-manifest.json，手册补充复盘与观测章节；旧.sil/.cor仍按可理解字段读取。

## 上一版：0.1.0-alpha.5 · 自由设计工作区

源码与脚本发行：Windows用run.bat，Mac用run.command，Linux用bash run.sh。需Python3.12；首次在项目虚拟环境安装固定依赖，无exe/app。Linux按用户请求新增脚本，未做平台验证；自动三平台验证已停用，只生成手册与源码附件。

- 核心表格共用列宽：名称/分类、实例数、L2容量、私有/全组共享、目标GHz和删除一一对应。频率0明确显示自动，小窗口可横向滚动。
- x86增加64位整数设计/执行器：16GPR、32位别名零扩展、REX、指定MOV/算术/IMUL/shift/Jcc/基址访存。32/64分别保存；没有OS、分页、SSE/AVX或完整x86。
- 核心模板扩充精简、均衡、宽发射、计算吞吐方向，覆盖x86-64、Arm64与RISC-V；每个模板有可编辑完整硬件定义。
- 独立自由沙盒入口与独立存档。签核给出潜在问题、原因和改善方向，不按任务/预算/许可条件阻止预览。普通项目约束保留；未知语义和无效输入仍不能解析。
- 芯片/封装PDN可输入等效电阻，以I×R展示压降。设备散热器默认折叠为整机厂商的使用场景；芯片侧负责功耗和封装取舍。
- 作者动机、联系渠道与未来愿景保留，图文手册覆盖启动、四类核心、SoC、挑战、64位x86、沙盒、诊断和导出分享。

本版对改变的功能做本地回归、界面与源码包检查，未运行Linux验证或重复平台矩阵。当前是功能与资源教学模型，没有玩家RTL生成、真实PDK签核或实际流片；自由预览不是物理验证证明。

完整解压SiliconImmortal-source.zip，先装Python3.12，再用平台脚本启动。附docs/player-guide/index.html离线手册与SHA256SUMS.txt。
