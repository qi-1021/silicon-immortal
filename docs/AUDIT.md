# 技术审查记录

## 已修正的模型与表达

| 问题 | 修正 | 仍然存在的简化 |
| --- | --- | --- |
| L2 面积乘了目标 SRAM 密度后又乘逻辑缩放比 | SRAM 只按目标节点 mm²/MB 计一次 | 未运行 CACTI 或真实 SRAM compiler |
| 带宽速率变量名和单位不清楚 | MT/s × x16 通道 × 16/8000 = GB/s | 固定有效率，无真实控制器 trace |
| RISC-V 固定额外 4% 面积 | 移除 ISA 的固定面积惩罚 | 微架构面积仍为参数模型 |
| GPU 各类核心数量转换成统一 CU | 显示原架构单元，明确不等价 | GPU 吞吐/驱动仍用系数 |
| AI 综合能力标成 TOPS | 分离 NPU INT8 峰值与 AI 综合分 | 旧 JSON ai_tops 字段保留兼容注释 |
| 功耗按固定温度求持续值 | 耦合持续结温与 CPU 漏电 | 峰值参考温度与非 CPU 功耗仍简化 |
| 至少一颗好 die、至少 5% 分档率 | 使用期望数量，分档下限改为数值稳定的 0.01% | 最差组代理全芯片相关工艺分布 |
| 两颗 Chiplet 都受 CPU 频率档位影响 | CPU bin 只作用于 CPU die | 没有独立 GPU 频率 bin |
| 散热方案显示费用但未计入成本 | DRAM、存储、散热在 platform_total 计价 | 整机配套不是完整 BOM |
| 降价产生无限需求 | 限制可服务市场上限 | 没有产能、库存和渠道 |
| 签核页锁住，主入口却仍能流片 | 共用 signoff.ready 和修复建议 | 门槛由游戏设定 |
| 修改芯片后旧展示数据和图像不更新 | 重算刷新全部指标与画布 | 没有设计历史版本管理 |
| 图鉴筛选后按全列表索引显示另一颗芯片 | 按稳定 ID 取详情，补空结果状态 | 未自动核验外部链接 |
| 所有 SoC 都不能混用不同 ISA | 仅限制同一应用核集群；说明异构控制核可行 | 没有异构软件执行模型 |
| Chiplet 必须使用 2.5D 被写成事实 | 表明这是本作唯一实现的封装方案 | 不支持有机基板、3D 或 UCIe 物理模型 |
| 十核被写成所有 Arm DSU 的上限 | 表明是教学惩罚，真实上限看 IP 版本 | 缺少显式一致性目录与簇拓扑 |
| 8W 会烧毁、折叠散热必然减半 | 改成具体情景预算和温度检查 | 设备形态参数仍是情景假设 |
| 高温直接推断一年后“缩缸” | 改为教学应力系数，不预测实际寿命 | 未实现 BTI/HCI/EM 寿命模型 |
| 未核验近期视频和 die shot 被当成证据 | 标注来源状态，撤下真实故障与排名断言 | 尚未逐项校准所有历史资料 |
| 示意图被称为真实硅片照片 | 仅保留玩家布局生成图，移除独立照片 | 不能生成玩家电路的真实显微照片 |
| 文件同时记载两个不同模型标识 | 由MODEL_VERSION统一生成 | 模型版本仍不用于校准实物 |
| 导入NaN、负容量、分数核数与巨大核数 | 已知字段、范围、类型与引用在仿真前检查 | 上限是软件资源与模型输入约束 |
| IA-32实验IP被标为x86_64 | 改为x86_32并维持异构应用集群检查 | IA-32保持32位；另有独立AMD64整数子集，无OS/SIMD |
| LAB主要是教程与示例输入 | 默认改为CPU/GPU/NPU/ISP核心设计台，硬件与测试台分开 | 参数化结构，尚无任意RTL/逻辑连接 |
| 自定义资源对调度没有明确影响 | CPU顺序/乱序、ALU/乘除端口、cache几何；GPU驻留和发射/延迟；ISP可旁路模块接入模型 | 非真实厂家微架构，PPA未校准 |
| 修改测试输入后旧表格仍显示 | 清除测试输出，保留独立固定验证与硬件身份 | 测试仍在UI线程执行 |
| .sil只带模板ID，目录更新改变设计 | 内嵌模板全参数/名称/参考制程，导入和再导出优先快照 | 运行公式与非核心模型目录仍可能随版本变化 |
| 架构页显示默认GPU而实际绑定定制IP | 展示实际绑定，换回模板解除绑定；导入模板名称也优先文件 | 加速器接口/驱动未完整建模 |

中端关卡改为 2020，保留旧内部 ID 以兼容存档，移除该关的 2023 年 SMIC N+2 选项。研究 GPU 加入 IP 使用范围与年份检查，手机关卡不接受服务器/笔记本散热器方案。

## 已加入的可玩机制

工程验证页提供三种相对 PVT 情景、验证与供电投入、内存通道/容量、Amdahl/Roofline 分析以及方案对照。新增第十四课有可通过的解法，验证投入、PDN 投入和频率调整均有明确结果。

晶圆图与成本使用相同完整矩形排版。独立真实参考照片已经移除；成品图只关联玩家布局。PicoRV32真实RTL以独立入口测试，不伪装成玩家生成的物理实现。

## 真实芯片设计中仍缺少的环节

| 环节 | 真实工作 | 本作状态 |
| --- | --- | --- |
| 产品定义 | workload、ISA、内存容量、接口、功耗、成本、生命周期 | 有情景目标与抽象工作负载 |
| 微架构 | 预测、流水线、乱序、端口、寄存器文件、一致性协议 | 动态轨迹依赖/ROB/端口调度与提交回放；无推测与一致性 |
| RTL | HDL、复位、时钟/电源域、低功耗控制、接口协议 | 固定PicoRV32上游RTL独立冒烟；玩家设计不生成RTL |
| 功能验证 | UVM、断言、formal、覆盖率、回归与 bug 修复 | 功能解释器与手算向量回归、IP导入重验；SoC验证仍是投入代理 |
| 综合 | 网表、面积、约束、等价检查 | 仅面积与频率代理值 |
| 物理实现 | 宏、placement、CTS、route、寄生、STA、OCV | 矩形布局与走线长度 |
| 电源/信号完整性 | IR、动态 droop、EM、SI、ESD、latch-up | 等效 I×R 代理值 |
| 物理验证 | DRC、LVS、ERC、天线效应、密度与填充 | 未实现 |
| 可测试性 | scan、MBIST、ATPG、故障覆盖与测试时间 | 未实现真实测试 |
| 封装 | bump map、基板、互连、热机械、KGD 与组合良率 | 简化费用与热阻 |
| 制造 | 光罩、reticle field、工艺偏差、SRAM 修复、wafer sort | Murphy 与 bin 代理值 |
| 上板/软件 | boot ROM、安全启动、固件、OS、驱动和调度 | 仅软件投入系数 |
| 可靠性 | 温压任务谱、加速应力、HTOL、BTI/HCI/EM | 仅游戏风险与应力情景 |
| 商业 | 周期、产能、渠道、采购、库存、授权条款和合规 | 简化有限需求与利润 |

## 若继续追求《图灵完备》式学习深度

目前已有组合ALU、四个ISA整数子集、动态轨迹时序和单层缓存trace实验。后续应增加玩家连接逻辑门/寄存器的可执行电路、有限物理寄存器、推测/恢复、缓存层级与一致性协议。现有实验必须通过实际输出验证；SoC模型分继续单独标明估算。

完整 PDK 签核需要真实 EDA 生态；即使接入开源 RTL、综合和布局工具，也应分开呈现工具输出、解析估算和游戏市场假设。当前版本把这些边界明确展示，不把参数数量等同于专业精度。

## 当前覆盖与审查结论

核心设计台支持四类命名硬件草稿、结构、固定验证、发布、.cor交换与SoC复用。四个CPU执行器是明确列出的整数子集；历史目录35项不是全集。GPU/NPU/ISP可设计对应资源并执行功能测试，不具备完整GPU软件栈、TPU实现或完整相机系统。18节进阶课与14节设计课有可运行参考解，并附来源支持范围。

资料库49条分别标注正文/书目/仅定位状态；99条遗留引用全部给出处置原因。PPA均为`game_assumption`，不会因为同一厂家或主题存在论文就自动升级成实测。Murphy仅有书目核验；具体良率函数未由全文确认。

交换文件将游戏、结构、模型版本分开。已知结构优先，未来版本不因数字不同被拒；未知SoC附加字段提示，旧IP附加配置保留参与摘要。新硬件语义和模板模型未知字段不能静默忽略。完整核心包缺少定义、摘要/类别失配报错；旧.sil提示目录依赖，合法未签核草稿仍可导入。

可复查例子见[examples](examples/README.md)，测试、UI检查和剩余限制见[本轮审查记录](REVIEW.md)。

自由沙盒单独保存/进入；签核诊断不以任务门槛阻止预览，不意味着真实约束消失。芯片PDN以显式等效电阻或投入代理调节，设备散热独立标为使用条件。表头与核心行共用宽度与单位。
